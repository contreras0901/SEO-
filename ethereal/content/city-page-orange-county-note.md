# Note: there is no /orange-county page

**Status:** Recommendation, not a page draft. No file needs to be published from this note unless the owner chooses to build the hub page below.

## What exists today

The site has individual pages for two Orange County cities: Newport Beach and Yorba Linda. The service area page lists Orange County as a covered county. There is no page at /orange-county, and no page that targets the phrase "Orange County restroom trailer rental" directly.

## Two options

**Option A: build an Orange County hub page.**
A county-level page can rank for "restroom trailer rental Orange County" and similar searches that do not name a city. It would link down to Newport Beach and Yorba Linda, and it gives the owner a place to add more OC cities later without building a full page for each one. This is the better option if Orange County bookings are a real part of the business or a growth target.

**Option B: leave it.**
If Orange County is a small share of bookings, a thin hub page adds little. The two city pages and the service area page already establish coverage. Revisit if OC inquiries grow.

**Recommendation:** Build the hub page only if the owner can supply at least two or three real details about OC deliveries (areas served, typical event types, delivery fee range). Without those, the page will read as generic and should wait.
