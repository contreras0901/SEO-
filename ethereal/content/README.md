# Ethereal Luxury Restrooms: website copy drafts

These Markdown files are draft copy for etherealluxuryrestrooms.com: four rewritten city pages (San Diego, Chula Vista, Los Angeles, Thousand Oaks), a note on the missing Orange County page, and four blog posts. Every fact in the drafts comes from the live site as of 2026-11-21 (fleet sizes, design lines, published pricing guide, contact details, service area). Anything the site does not state, such as lead times, hookup requirements, trailer dimensions, permits, delivery fees, and guest-count-to-stall guidance, is written as a bracketed placeholder in the form [FOUNDER: ...]. Every one of those placeholders must be filled with a true answer or deleted before the page goes live. Do not publish a page with a placeholder still in it, and do not guess at an answer on the owner's behalf. Note on the blog posts: the site is built on Showit and has no blog today. Publishing the posts requires either a Showit blog page set up as a series of static pages, or the Showit plus WordPress blog add-on, which is the standard way to run a real blog on a Showit site. Decide on that before editing the posts, because the add-on changes how internal links and post URLs are set up.
